01 — Problem

Developers keep asking: why is this code written this way?

Existing tools each answer one slice. None of them connect the answers into one queryable chain.

git blame

Tells you who changed a line — not why it changed, or which constraints shaped it.

GitHub search

Text only. PR threads sink after a few years and retrieval becomes expensive.

ADR tools

Require manual writing. Docs drift from code; coverage stays incomplete.

AI coding assistants

Usually see only the current file — not historical constraints or rejected alternatives.

02 — Solution

Three layers, one graph

Parse code with tree-sitter into AST relations (uses / defined_by) and store them in Dgraph, then overlay the Git timeline and decisions from PRs, issues, and ADRs. Query any historical snapshot of the code graph — or the decision behind a single line.

Input Source repository Python / TypeScript
Input Git history commit · blame · diff
Input Decision sources PR · Issue · ADR
Parse tree-sitter AST · uses · defined_by
Extract Decision extractor reason · alternatives · status
Store Dgraph CodeNode · Decision · Discussion
Serve CLI · Web · AI context why / graph / export
01

Time travel queries

codegraph graph --at 2024-06-01 returns the structure at that moment — not today’s HEAD.

02

One line → decision provenance

codegraph why file:line emits a decision card: reason, alternatives, discussion, whether it was superseded.

03

Conflict detection

codegraph conflicts finds contradictory accepted decisions so rules do not fight each other.

Seven core commands

Stable interfaces first. Every command supports --help.

core

--scope

05 — Graph model

Three entity types; relations are the answers

The schema is a core contract. Changes require a migration plan and explicit confirmation.

CodeNode Structure
  • kind function / class / …
  • file_path source location
  • valid_from/to validity window
  • uses reference edges
  • decided_by → Decision
Decision Decision
  • content what was decided
  • reason why
  • alternatives what was rejected
  • status accepted / superseded
  • justifies → CodeNode
Discussion Discussion
  • platform github / gitlab
  • title topic
  • url deep link
  • participants people
  • created_at time
