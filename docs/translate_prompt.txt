## 待译：项目描述（约 80 词）

程序员经常问「这段代码为什么这么写？」git blame 只告诉你是谁改的；
GitHub 搜索只能搜文本；PR 讨论几年后就沉了；ADR 要求人工维护；
AI 助手通常只看当前文件。CodeGraph 用 tree-sitter 解析代码成 AST，
把 uses / defined_by 等关系存入图数据库，叠加 Git 时间轴与 PR/Issue/ADR
决策信息。支持查询任意历史时刻的代码图，也支持查某一行代码背后的决策来源。
一句话：把代码结构、历史变更和设计决策变成一张可查询的图。

## 待译：三条创新点

1. 首次用图数据库原生整合「静态结构 + 设计决策 + Git 时间」，支持多跳关联查询。
2. 提供 codegraph why <file>:<line>，把一行代码映射到可追溯的决策来源卡片。
3. 支持 --at 历史时刻查询，回答「当时结构如何、为何如此」，而不是只看 HEAD。
